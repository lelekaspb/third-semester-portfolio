# Olga Baeva — Portfolio

A responsive portfolio website built with HTML, CSS, and JavaScript. The home
page presents selected projects, approach, skills, experience, and contact
information. All page content lives in `js/model.js` and is rendered into
`index.html` by `js/view.js` (MVC with IIFE modules).

Open `index.html` in a browser to view the portfolio. There is no build step.
